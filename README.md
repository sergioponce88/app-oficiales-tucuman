# App de Oficiales — Policía de Tucumán (piloto)

App instalable (PWA) del sistema piloto para oficiales. Solo contiene el ícono, la pantalla de inicio y el acceso
al sistema; el código y los datos están en un repositorio privado.

Instalar: abrir https://sergioponce88.github.io/app-oficiales-tucuman/ en el teléfono y tocar «Instalar».
